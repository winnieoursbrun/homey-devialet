Connect and control your Devialet audio devices directly from Homey.
This app provides seamless integration with Devialet phantom speakers, allowing you to manage playback, adjust volume, and monitor device status through your smart home automation system.

Tested models:
- Phantom I
- Phantom II
- Mania

Limitations:
- Multi-room group creation must be done through the official Devialet app (no API documentation available for this functionality)
- Power on is only possible via physical button (not available through API)
- Stereo pair configuration must be done through the official Devialet app
